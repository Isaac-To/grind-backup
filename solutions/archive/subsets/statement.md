# 78. Subsets

**Medium** · Backtracking · [problem on LeetCode](https://leetcode.com/problems/subsets/)
Fluency target: 30 min (prior)

---

Given an integer array `nums` of **unique** elements, return *all possible* *subsets* *(the power set)*.

The solution set **must not** contain duplicate subsets. Return the solution in **any order**.

 

**Example 1:**

```

**Input:** nums = [1,2,3]
**Output:** [[],[1],[2],[1,2],[3],[1,3],[2,3],[1,2,3]]

```

**Example 2:**

```

**Input:** nums = [0]
**Output:** [[],[0]]

```

 

**Constraints:**

	
- `1 <= nums.length <= 10`

	
- `-10 <= nums[i] <= 10`

	
- All the numbers of `nums` are **unique**.

---

*The examples above are pre-loaded into `TESTS` in the solution file,
with extra hand-written edge cases after them — `grind check` runs the
first few, `grind done` runs all of them and grades.*
